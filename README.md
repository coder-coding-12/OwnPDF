# 🖼️ Image to PDF

A simple and user-friendly web app that converts multiple images into a PDF directly in your browser. 🚀

## ✨ Features

* 📷 Select multiple images
* 👀 Preview images before creating the PDF
* 📄 Convert images into a PDF
* ⚡ Fast and easy to use
* 🔒 Images are processed directly in your browser

## 🛠️ Built With

* HTML
* CSS
* JavaScript
* jsPDF

## 🚀 How to Use

1. Open the website.
2. Select one or more images.
3. Arrange your images if needed.
4. Click **Create PDF**.
5. Download your PDF.
